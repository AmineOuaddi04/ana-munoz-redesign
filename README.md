# Ana Muñoz · dos propuestas de rediseño

Dos direcciones para Peluquería Ana Muñoz, Av. de Colón 9, Logroño. Son demos de presentación, no la web oficial del negocio.

- [Dirección 01 · Editorial](https://amineouaddi04.github.io/ana-munoz-redesign/) — identidad tipográfica, azul del patio e historia del salón.
- [Dirección 02 · El oficio a primera vista](https://amineouaddi04.github.io/ana-munoz-redesign/v2/) — corte y color visibles desde la portada, servicios directos y cita fácil.

El archivo [05-ana-munoz-demo.zip](05-ana-munoz-demo.zip) contiene el código fuente, ambas webs estáticas, fotografías y documentación. Al descomprimirlo, ejecuta `node serve.mjs` con Node 22 o posterior y abre `http://127.0.0.1:4174/` o `http://127.0.0.1:4174/v2/`. No hay dependencias que instalar.

La segunda dirección usa dos fotografías generadas como concepto, identificadas como tales en cada página; no representan trabajos ni clientes reales del salón. Las fotografías auténticas del local son de noviembre de 2020. Origen y límites de uso en `FUENTES_FOTOGRAFIAS.json` y `V2-NOTAS.md` dentro del ZIP.

## Para convertir una propuesta en web oficial

Confirmar con Ana los servicios, horarios, canal de citas y textos; obtener fotografías actuales autorizadas; preparar avisos legales y revisar las rutas históricas. Ambas demos están configuradas con `noindex,nofollow`. No recogen datos ni reservan citas automáticamente.
